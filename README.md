# Rudrani Wedding Planner

A responsive bilingual landing page for Rudrani Wedding Planner. The site showcases wedding planning services in Hindi and English, presents a premium invitation-inspired visual identity, and provides direct WhatsApp and phone contact actions for prospective clients.

## Key Technologies

- TanStack Start
- React 19 and TypeScript
- Vite
- Tailwind CSS 4
- Lucide React
- Netlify

## Run Locally

Install dependencies and start the development server:

```bash
pnpm install
pnpm dev
```

The application is then available at the local URL printed by Vite.

## Production Build

```bash
pnpm build
```

Netlify uses the project configuration in `netlify.toml` to build and deploy the site.
